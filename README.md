# Zzz

Мультиплатформенный C++23 фреймворк для создания современных UI-приложений с интеграцией 3D-графики.

## Цели проекта

Главная цель проекта — подготовить надёжную и легковесную технологическую базу под запланированное коммерческое прикладное приложение (детали не раскрываются), сочетающее современный интерфейс, 3D-графику и энергоэффективность:

- **Unity/Unreal-подобный workflow:** общая идеология разработки строится вокруг визуальной настройки проекта, сцен и UI в редакторе с последующей генерацией готовых платформенных билдов. На текущем этапе подготовку платформенных проектов и сборку бинарных пакетов ресурсов выполняет **Assets Builder**.
- **WPF-подобный UI-слой (MVVM):** собственные элементы UI с On-Demand рендерингом (кадр отрисовывается только при наличии изменений), что существенно экономит заряд батареи на мобильных устройствах и ноутбуках при отсутствии непрерывной анимации.
- **Интеграция 3D-графики:** возможности 3D-движка на кроссплатформенном GAPI (DirectX 12, Vulkan, Metal) с бесшовным встраиванием интерактивных 3D-элементов и шейдерных эффектов прямо в компоненты интерфейса.
- **C++ скриптование:** написание логики UI и поведения сцены на чистом C++ для максимальной отзывчивости без оверхеда виртуальных машин и сборщиков мусора.
- **Инфраструктура ресурсов:** собственный **Assets Builder** для сборки исходных ассетов в компактные бинарные пакеты (`package.dat`, `data.dat`, `.meta`) с асинхронной потоковой загрузкой в рантайме.

### Текущая контрольная точка (MVP)
Реализация сквозного цикла: от подготовки ассетов в Assets Builder до асинхронной загрузки и рендера вращающегося 3D-куба, минимального интерфейса, с пользовательскими C++ скриптами через GAPI (DX12/Vulkan/Metal).

## Требования к окружению (Windows)

- Visual Studio 2022 / 2026 (MSVC с поддержкой стандарта C++23).
- CMake 3.28+ и Ninja.
- .NET 8 / 9 SDK (для сборки C# инструментов и редактора).

> Инструкции по настройке окружения для других платформ (Linux/WSL, macOS, iOS) вынесены в **[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)**.

## Сборка и начало работы

### 1. Настройка конфигурации сборки

Управление включением модулей, тестов и выбором графического бэкенда (DirectX 12 / Vulkan) осуществляется через файл `build_configs/current.cmake`.

Для настройки и переключения конфигурации используются:
- **Консольный свитчер (C++):** `build_configs/build_configurator_switch.exe` (первичная сборка: `automation\build_config_switcher.bat`).
- **Графический конфигуратор (WPF):** `build_configs/BuildConfigurator.exe` (первичная сборка: `automation\build_configurator.bat`).

### 2. Сборка на Windows

Сборка выполняется двумя основными способами:
- **Через батник:** запустить `run_build.bat` в корне репозитория (компиляция через CMake + Ninja в конфигурации Debug).
- **Через Visual Studio:** открыть корень репозитория как папку (**Open Folder**). Visual Studio автоматически подхватит `CMakePresets.json`. Выбрать нужную конфигурацию (`Debug`, `Release`, `Development`) и собрать проект.

Все скомпилированные исполняемые файлы, библиотеки и инструменты помещаются в каталог:
`dist/<Config>/` (например, `dist/Debug/`).

## Инструменты разработки

Все инструменты и вспомогательные C# проекты объединены в общее решение **`src/tools/Tools.sln`** для удобной сборки и совместной отладки с C++ движком:

| Инструмент | Описание | Путь к бинарнику | Способ сборки |
| :--- | :--- | :--- | :--- |
| **Assets Builder** | Утилита сборки ассетов в пакеты ресурсов (`package.dat`, `data.dat`) | `dist/<Config>/assets_builder_gui.exe` | Автоматически в CMake (`assets_builder_gui_build`) или через `Tools.sln` |
| **Editor** | C# WPF редактор сцен и проекта (разработка начата, но отложена из-за объёма и низкого приоритета на текущем этапе) | `dist/<Config>/editor.exe` | Через `src/tools/Tools.sln` |
| **Remote Log Viewer** | Сетевой просмотрщик логов движка в реальном времени | `dist/<Config>/RemoteLogViewer.exe` | Автоматически в CMake или через `Tools.sln` (ярлык в корне: `RemoteLogViewer.lnk`) |
| **Build Configurator** | Графический редактор профилей сборки (WPF) | `build_configs/BuildConfigurator.exe` | `automation\build_configurator.bat` или `Tools.sln` |
| **Config Switcher** | Консольный свитчер конфигураций (C++) | `build_configs/build_configurator_switch.exe` | `automation\build_config_switcher.bat` |

## Тесты и бенчмарки

В проекте используются Google Test и Google Benchmark (`src/qa/tests` и `src/qa/benchmark`).

- Включение сборки тестов регулируется дефайном `Z_ADD_PROJECT_TESTS_IN_BUILD` в активной конфигурации (`build_configs/current.cmake`).
- Исполняемые файлы тестов собираются в `dist/<Config>/EngineTests.exe` и `dist/<Config>/EngineBenchmarks.exe`.
