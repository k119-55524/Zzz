## 🎯 Архитектурный переход: Метаданные в TOC вместо блоб-заголовков в `.pak`

В ходе этапа 25 была принята более производительная и чистая zero-copy архитектура:
1. **Отказ от `TextureBlobHeader` внутри `.pak`:**
   Вместо того чтобы приклеивать 64-байтный заголовок перед каждым ассетом внутри `.pak`, метаданные вынесены непосредственно в оглавление `data.dat`.
2. **`union AssetMetadata` в `PackageEntry` (32 байта):**
   В оглавление `data.dat` для каждого ресурса добавлено фиксированное 32-байтное поле `AssetMetadata`, в котором для текстур хранится компактная структура `TextureMetadata`.
3. **Чистый GPU-payload в `.pak` файлах:**
   Файлы `.pak` (например, `0004.pak`) теперь содержат строго полезную нагрузку мип-уровней без оверхеда на заголовки и без сдвигов выравнивания.

## 📐 Архитектурные спецификации

### 1. Метаданные текстуры в TOC (`TextureMetadata`, 32 байта)
Располагается в `src/core/io/package/assets/AssetMetadata.h` и входит в `PackageEntry`:
```cpp
namespace zzz::core
{
    struct TextureMetadata
    {
        zU32         width{ 0 };                             // Ширина в пикселях (кратна 2)
        zU32         height{ 0 };                            // Высота в пикселях (кратна 2)
        zU16         depth{ 1 };                             // Глубина (1 для 2D)
        zU16         arraySize{ 1 };                         // 1 для 2D, 6 для Cube
        ePixelFormat format{ ePixelFormat::Unknown };        // Формат пикселей / GPU сжатия
        zU8          mipCount{ 1 };                          // Количество мип-уровней (от 1 до 16)
        eTextureType textureType{ eTextureType::Texture2D }; // 2D, Cube, 3D, 2DArray
        zU8          flags{ 0 };                             // Бит 0: sRGB, Бит 1: IsNormalMap
        zU8          reserved[15]{ 0 };                      // Резерв
    };
    static_assert(sizeof(TextureMetadata) == 32, "TextureMetadata must be exactly 32 bytes");
}
```

### 2. Библиотека `texture_builder`
Располагается в `src/texture_builder/`:
- **`stb` (`stb_image.h`, `stb_image_resize2.h`):** распаковка в RGBA8, качественный даунскейл цепочки мипмапов с гамма-коррекцией (`stbir_resize_uint8_srgb` / `stbir_resize_uint8_linear`).
- **`DirectXTex`:** компрессия в нативные GPU-форматы BC1–BC7 для десктопных платформ (`Z_DESKTOP`).
- **Изоляция:** сборка DirectXTex отключена для мобильных платформ (`if(NOT ANDROID AND NOT IOS)`), а линковка выполнена `PRIVATE`.
- **Класс `TextureBuilder`:**
  * Инспекция метаданных без декодирования (`Probe`) через `stbi_info`.
  * Валидация: кратность двум (`requireDivisibleByTwo`) и максимальное разрешение (`maxDimension`).
  * Генерация мипмапов и компрессия (`Convert`).

> [!NOTE]
> Специализированные методы (`ProcessNormalMap`, `PackChannels`, `BuildAtlas`, `BuildCubemap`) заложены в интерфейсе в виде заглушек и оставлены на будущее расширение при необходимости соответствующих фичей в редакторе/пакере.
