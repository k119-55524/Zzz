## 1. Цель этапа
Реализовать базовые структуры векторной математики `Vec2`, `Vec3`, `Vec4` для описания геометрических координат, нормалей, текстурных координат и цветов в 3D пространстве с полной совместимостью с типами шейдеров (HLSL, GLSL, MSL).

## 3. Технические требования к реализации

### 3.1. Типы данных и шаблоны:
- Базовый шаблон: `template<zzz::math::Arithmetic T = float> struct Vec2`, `Vec3`, `Vec4`.
- Псевдонимы типов (Typedefs):
  - `Vec2f` / `Vec2` $\to$ `Vec2<float>`
  - `Vec3f` / `Vec3` $\to$ `Vec3<float>`
  - `Vec4f` / `Vec4` $\to$ `Vec4<float>`
  - `Vec2i`, `Vec3i`, `Vec4i` $\to$ `int32_t`
  - `Vec2u`, `Vec3u`, `Vec4u` $\to$ `uint32_t`

### 3.2. Макет памяти (Memory Layout):
- Открытые поля `x, y`, `x, y, z`, `x, y, z, w`.
- Доступ по индексу `operator[](size_t index)`.
- Прямой доступ к сырым данным: метод `data()` и оператор `const T*`.
- Проверка через `static_assert`:
  - `std::is_standard_layout_v<Vec3<float>> == true`
  - `sizeof(Vec2<float>) == 8`
  - `sizeof(Vec3<float>) == 12`
  - `sizeof(Vec4<float>) == 16`

### 3.3. Набор математических операций:
1. **Арифметика:**
   - Покомпонентные операторы `+`, `-`, `*`, `/`.
   - Скалярное умножение и деление: `v * s`, `s * v`, `v / s`.
   - Унарный минус: `-v`.
   - Операторы составного присваивания: `+=`, `-=`, `*=`, `/=`.
   - Операторы сравнения: `==`, `!=` (с учетом машинного epsilon для чисел с плавающей точкой).
2. **Векторные функции:**
   - Скалярное произведение: `Dot(a, b)` / `a.Dot(b)`.
   - Векторное произведение (для `Vec3`): `Cross(a, b)` / `a.Cross(b)`.
   - Длина: `Length()`, `LengthSquared()`.
   - Нормализация: `Normalize()` (in-place), `Normalized()` (копия), безопасная обработка нулевого вектора.
   - Расстояние: `Distance(a, b)`, `DistanceSquared(a, b)`.
   - Линейная интерполяция: `Lerp(a, b, t)`.
   - `Min(a, b)`, `Max(a, b)`, `Clamp(v, min, max)`.
   - Отражение: `Reflect(v, normal)`.
3. **Статические константы:**
   - `Zero()`, `One()`, `Up()` $(0, 1, 0)$, `Down()` $(0, -1, 0)$, `Left()` $(-1, 0, 0)$, `Right()` $(1, 0, 0)$, `Forward()` $(0, 0, 1)$, `Back()` $(0, 0, -1)$.
4. **Форматирование и логирование:**
   - Специализация `std::formatter` для прямой поддержки в `std::format` и `DOut("Pos: {}", v)`.
