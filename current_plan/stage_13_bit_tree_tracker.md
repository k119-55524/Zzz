# Этап 13: 64-арное битовое дерево изменений (`BitTreeTracker`)

## 1. Контекст и цели этапа
- **Номер пункта:** **Пункт 13** (Уровень 2: GAPI-ресурсы, содержимое куба и сквозной рендер).
- **Цель:** Разработать фундаментальную, не зависящую от движка структуру данных `BitTreeTracker` в модуле `core`:
  1. $O(1)$ пометка битов изменений через `Set`.
  2. 64-арная иерархическая организация: каждый уровень редуцирует 64 бита нижележащего уровня в 1 бит родителя (`uint64_t`).

  4. Быстрая очистка за $O(1)$ при отсутствии изменений (проверка флага `m_IsDirty`) или блочным занулением буфера.
  5. Покрытие специфицированных сценариев модульными тестами.

- **Зависимости:** `src/core/CoreIncludes.h`, компиляторные интринсики `_BitScanForward64` (MSVC) / `__builtin_ctzll` (GCC/Clang).

## 2. Архитектурная спецификация `BitTreeTracker`

### 2.1. Математическая модель 64-арного дерева
Для отслеживания изменений в $N$ узлах (листьях) дерево формирует уровни (Levels):
- **Уровень 0 (Листья):** битовая маска узлов. $K_0 = \lceil N / 64 \rceil$ слов `uint64_t`. Бит $i$ означает, что узел $i$ изменён (`isDirty`).
- **Уровень 1:** $K_1 = \lceil K_0 / 64 \rceil$ слов. Бит $j$ означает, что в слове $j$ уровня 0 есть хотя бы один установленный бит.
- **Уровень $L$ (Корень):** ровно 1 слово `uint64_t`. Корень хранит агрегированное состояние дерева, но быстрый публичный путь "нет изменений" выполняется через `m_IsDirty`, чтобы не зависеть от чтения корневого слова.

Все уровни упакованы в **один непрерывный массив** `std::vector<uint64_t> m_Words`. Пустая сцена передаёт `capacity == 0`; трекер нормализует это значение до внутренней емкости 1. Пустого внутреннего состояния нет.

Внутренний `constexpr`-массив префиксных смещений содержит границы уровней в `m_Words`: `0`, `1`, `65`, `4161`, `266305`, `17043521`, `1090785345`. Для текущих `m_Depth` и `level` `GetLevelOffset(level)` берёт смещение по расстоянию от корня. Та же таблица задаёт суммарный размер дерева и разность соседних значений определяет вместимость листового уровня; отдельный `m_LevelOffsets` и его пересчёт не нужны.

`Prepare()` сначала проверяет, что входная емкость покрывается последней ступенью таблицы; при превышении выбрасывается `THROW_RUNTIME` и в Release. Затем короткий цикл выбирает минимальную глубину.

`m_DirtyIndices` — только переиспользуемый выходной буфер. При `m_IsDirty == false` `GetDirtyIndices()` сразу возвращает пустой `span`, не трогая буфер. При наличии изменений метод очищает буфер и заново обходит дерево; отдельного кеша результата и флага валидности кеша нет.

`Prepare(capacity)` нормализует `0` до `1`, затем обновляет логическую `m_Capacity`; при уменьшении емкости ранее выделенный буфер не сжимается. `Set(index)` требует `index < m_Capacity`: нарушение проверяется через `ensure`. `GetDirtyIndices()` возвращает индексы строго по возрастанию индекса слота (гарантируется порядок слотов SoA, топологический порядок parent-before-child НЕ гарантируется). Возвращаемый `std::span` валиден строго до следующего вызова `Prepare()`.

### 2.2. Спецификация класса `BitTreeTracker`

```cpp
namespace zzz::core
{
    class BitTreeTracker final
    {
    public:
        explicit BitTreeTracker(uint32_t initialCapacity = 1);

        /// @brief Подготовка трекера к кадру: гарантирует емкость под число элементов и сбрасывает все биты в 0.
        void Prepare(uint32_t capacity);

        /// @brief Установка бита по индексу узла (O(1) по числу уровней пирамиды). index < Capacity - доверенный контракт вызывающей стороны (аналог GUID из Правила 15): проверка через ensure работает только в Debug/Dev, в Release - zero-overhead no-op без защиты от выхода за границы буфера.
        void Set(uint32_t index) noexcept;

        /// @brief Возвращает span со всеми собранными грязными индексами текущего кадра (0 аллокаций). Чистит внутренний буфер перед каждым обходом - безопасно вызывать повторно между вызовами Prepare(), результат не дублируется.
        /// @warning Возвращаемый span указывает на внутренний буфер трекера и валиден строго до следующего вызова Prepare() в текущем потоке. Порядок индексов - строго по возрастанию слотов SoA (не топологический).
        [[nodiscard]] std::span<const uint32_t> GetDirtyIndices();

    private:
        uint32_t              m_Capacity{ 1 };
        uint32_t              m_Depth{ 1 };
        bool                  m_IsDirty{ false };
        std::vector<uint64_t> m_Words;        // Единый непрерывный буфер всех уровней дерева (корень в m_Words[0])
        std::vector<uint32_t> m_DirtyIndices; // Переиспользуемый выходной буфер, не кеш
    };
}
```
