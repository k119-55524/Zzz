# Zzz Server Architecture

Модуль сервера предназначен для обработки сетевых подключений, поддержки нескольких типов трафика на разных портах, а также локального и удаленного управления через GUI админку по сети (RPC/Socket).

## Архитектура взаимодействия

```text
+----------------------------------------------------+
|               AdminPanelWin (C# WPF)               |
|  - Располагается в src/server/admin_panel_win      |
|  - Подключается по localhost (или remote IP)       |
|    к служебному Admin RPC порту сервера           |
+-------------------------+--------------------------+
                          |
             Admin Protocol (localhost:9004)
                          |
                          v
+-------------------------+--------------------------+
|            server_win (Dedicated Server Executable)|
|  - Самостоятельный консольный процесс              |
|  - Использует server_lib                           |
|  - Открывает служебный Admin RPC порт              |
+-------------------------+--------------------------+
                          |
                          v
+-------------------------+--------------------------+
|               server_lib (C++ Library)             |
|  - Мульти-портовый сетевой движок                  |
|  - Управление слушателями трафика                  |
+----------------------------------------------------+
```

## Компоненты

1. **`server_lib` (Server Core Library)**
   - C++ библиотека, содержащая ядро сетевого движка.
   - Поддержка нескольких портов и типов трафика (Reliable UDP, Unreliable UDP, File Transfer, Admin RPC).
   - Чтение и обработка конфигураций.

2. **`server_win` (Dedicated Standalone Server Executable)**
   - C++ консольное приложение (`.exe`) под Windows.
   - Использует `server_lib` для запуска выделенного (headless) сервера.
   - Открывает служебный Admin RPC порт для взаимодействия с админкой.

3. **`admin_panel_win` (AdminPanelWin WPF Application)**
   - C# WPF приложение на .NET Core / .NET 8.
   - Подключается к серверу по сокету/RPC для отправки команд управления (запуск/остановка портов, изменение конфига, мониторинг).

## Типы Трафика

- **Unreliable UDP**: Высокоскоростная передача данных реального времени без подтверждения (позиции объектов, state updates).
- **Reliable UDP / TCP**: Передача важной игровой логики с подтверждением доставки пакетов (события, чат, действия).
- **File Transfer**: Выделенный порт/протокол для передачи ресурсов, файлов и патчей.
- **Admin RPC**: Служебный порт для подключения админ-панели и управления сервером в рантайме.
